# MPL — instaladores e atualizações

Aqui ficam apenas os **instaladores** e as **atualizações** do MPL — Método Parametrizável de Loterias.
O código-fonte **não** está neste repositório.

- As versões são publicadas em **Releases** (ainda não há nenhuma: o MPL 2.0 está em desenvolvimento).
- O programa instalado avisa sozinho quando sai uma versão estável nova.
- Os pacotes são assinados; não instale o MPL obtido de outro lugar.

O MPL é uma ferramenta de organização e análise de jogos; não promete nem garante resultados. Apostas são para maiores de 18 anos.
